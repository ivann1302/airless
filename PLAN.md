# Airless Painting — Лендинг: Спецификация

**Дата:** 2026-04-15  
**Стек:** React + Vite, JSX, CSS (один файл на компонент)  
**Цель:** Доработать существующий прототип до полноценного лендинга по дизайну из pencil-new.pen

---

## Подход

Отдельный `.css`-файл на каждый компонент. Существующий код не рефакторится — только добавляются новые секции и минимально правится `Cta.jsx`.

## Детали компонентов

### StatsBar
- Белый или светло-серый фон
- 3–4 метрики: число + подпись (например «200+ объектов», «8 лет опыта»)
- Flexbox, равномерное распределение

### Services
- Каждая услуга — строка: текст (заголовок + описание) + цветной блок/иллюстрация
- Нечётные: текст слева, блок справа; чётные — наоборот
- Данные — массив объектов в компоненте

### HowWeWork
- Синий фон (как в дизайне)
- 4 шага с номерами и описанием
- Горизонтально на десктопе, вертикально на мобиле

### Portfolio
- CSS Grid 3 колонки (2 на планшете, 1 на мобиле)
- Карточки с заглушкой `background-color: #ccc` вместо фото
- Подпись под каждой карточкой

### Pricing
- 2–3 карточки, средняя — выделенная (акцентный цвет)
- Название тарифа, цена, список пунктов, кнопка

### Reviews
- Карточки: имя, текст отзыва, звёздный рейтинг (статичные звёзды через символы ★)

### Certificates
- Ряд прямоугольных плейсхолдеров (серый фон + подпись)

### Faq
- `useState` для открытого вопроса
- Клик на вопрос — разворачивает ответ, закрывает предыдущий

### FloatingCallButton
- `position: fixed; bottom: 24px; right: 24px`
- Круглая кнопка с иконкой телефона (unicode ☎ или SVG)
- `href="tel:+79990000000"`
- z-index поверх всего контента

### Cta (правка)
- Убрать `<form>`
- Добавить два `<a>`: `href="tel:..."` и `href="https://max.ru/..."` с классами `button primary` / `button secondary`

## Адаптивность

Все новые секции адаптируются под мобиле (≤768px): одна колонка, меньшие отступы. Используем простые CSS media queries без сторонних библиотек.
